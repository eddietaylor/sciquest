Inverse-propensity-weighted ridge regression

In workflows using this estimator, some observations are more likely under certain pricing policies. Inverse propensity weighting tries to rebalance the training data so the model does not simply learn the historical pricing policy. Ridge regression then supplies a prediction model, with regularization to avoid overfitting.

Log-demand space

A model using log-demand predicts the logarithm of demand instead of raw demand. This can stabilize variance and helps keep predictions positive after exponentiation.

Rank-aware objective

A rank-aware objective evaluates not only absolute error but also whether predictions correctly rank scenarios from better to worse.

Law-of-demand pass rate

This checks whether predicted demand usually decreases when price increases.

Validation Metric Definitions

Weighted aggregate score

Only primary metrics enter the weighted aggregate. Diagnostics remain separate; failed or undefined constraints withhold the aggregate.

\(S = \sum_i w_i s_i / \sum_i w_i\)

Policy value and regret

Actions are selected from model predictions. Protected expected outcomes determine their mean value and loss against the best listed action in each state. This requires justified intervention truth.

Constraint violation rate

Fraction of selected actions with a protected binary violation label. Constraints are evaluated separately from prediction error and utility.

WAPE

Weighted absolute percentage error. Lower is better for forecast/counterfactual error.

\(WAPE = \frac{\sum_i |y_i - \hat{y}_i|}{\sum_i |y_i|}\)

Relative WAPE lift

Improvement versus a baseline simulator or model. Higher is better.

\(Lift = (WAPE_{baseline} - WAPE_{model}) / WAPE_{baseline}\)

RMSE

Root mean squared error, used here for demand/unit prediction error. Lower is better.

\(RMSE = \sqrt{\frac{1}{n}\sum_i (y_i - \hat{y}_i)^2}\)

Rank correlation

Spearman correlation of true and predicted price-action rankings. Higher is better.

\(\rho = corr(rank(y), rank(\hat{y}))\)

Law-of-demand pass rate

Share of comparable states where predicted demand is non-increasing as price rises.

\(PassRate = \frac{1}{|G|}\sum_g 1[\hat{d}_{g,p_1} \geq \hat{d}_{g,p_2}\;\forall p_1<p_2]\)
